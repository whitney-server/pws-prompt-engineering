# PWS Prompt Engineering
Various prompts (typically for Claude or Gemini) to do the work required of PWS.

# Project-Setup
These prompts are part of the DoD (Definition of Done) for PWS services.
- `setup-docker.txt` - Configure Docker by connecting to the existing Docker network and using a provided URI. 
- `setup-jenkins.txt` - Configure Jenkins by creating a Jenkinsfile in the project.
